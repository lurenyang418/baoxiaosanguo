# 战役通关阶段记录｜2026-10-06

## 可玩功能

第 19 关胜利后按 A 打开通关记录。左右键切换 20 人队伍的两页，上下键选择“返回标题”或“保存通关记录”，按 A 执行；触屏可点页面箭头或操作项。保存会明确替换当前 Godot 演示存档。从标题或战斗系统菜单读取该记录会重新打开通关画面。开始新战役会清除待保存的通关记录。旧版 version 1 战斗存档仍沿用原有读取路径。

该通关摘要界面是复刻版 UI。原版 ROM 在胜利后递增 `$6400`；达到 `$13` 时会执行 bank `$15` 的 callback 0，而不是进入下一场战斗。当时尚未截取原版结局演出。
