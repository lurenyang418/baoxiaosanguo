# 爆笑三国 19 关地图候选图

打开 `index.html` 浏览；`overview.png` 是按关卡顺序排列的总览图，
`01.png`～`19.png` 是原生 256 像素宽的单关地图。图片和索引文件已直接保存在仓库中，无需另附 ZIP。

推荐使用 **PNG** 保存和对照 FC 像素地图：无损，缩放时可用“最近邻”保持像素边缘。
不要用 JPEG 保存母版；它的有损压缩会改变图块边缘的颜色。

这些图片由 ROM 地图、CHR 和调色板数据合成，不含单位、菜单及动画。
它们还没有逐关与原版实机截图做像素校准，属于地图候选图。
第 1 关使用单独校过部分画面颜色的候选图；其他关使用统一的
ROM 调色板合成流程。

重新生成：

```sh
python3 research/tools/render/build_map_gallery.py
```
