# 测试记录

这里保存适合随源码长期维护的测试计划、验收摘要和执行方法。克隆仓库即可查阅这些内容。

本目录只保存长期有效的计划、执行方法和验收结论。单次运行产生的日志、截图、隔离存档和机器环境信息不作为仓库文档依赖，也不在这里维护本机路径。

长期结论应整理到本目录的验收摘要或对应[阶段记录](../milestones/README.md)，注明测试日期、源码版本、测试范围、结果和限制。需要团队共享或审计的原始证据，应挑选必要文件并显式归档到项目内。
